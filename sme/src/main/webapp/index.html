    Vállje fiilla maid háliidat geavahit:
     

    Info

    Sáhtát geavahit iežat teavstta! Teaksta ferte leat .html formáhtas.
    Jus geavahat pdf-fiilla, de sáhtát konverteret html:n Adobe Acrobat-prográmmain. Jus geavahat Microsoft Word, de sáhtát vurket dokumeantta html:n dáinna lágiin:

    1. Raba dokumeantta Word:s
    2. Vállje Save as (Lagre som) File (Fil) fálus
    3. Vállje Web Page (webside) fiilla formáhtan.
      Fuobmá ahte boađus dábálaččat leat 'losses' html mii sáhttá sisttisdoallat html-gilkoriid mat eai doaimma juohke neahttalohkkiprográmmas.
      Jus vejolaš, vállje Web Page, Filtered (Nettside filtrert) mii ráhkada oktageardán html-fiilla.
